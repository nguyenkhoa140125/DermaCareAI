## 🚀 Quick Start

#### Windows (Recommended)

1. Extract the ZIP anywhere.

2. Double-click:

```text
START_DermaCare_AI.bat
```

3. Browser opens automatically.

4. Access:

```text
http://localhost:5090
```

5. Begin exploring dermatology information and educational tools.

## 🔧 Troubleshooting

#### Application Does Not Open

Open:

```text
START_DermaCare_AI.bat
```

or browse to:

```text
http://localhost:5090
```

using Chrome, Microsoft Edge, or Firefox.

#### Port Already In Use

Restart the application using:

```text
RESTART_DermaCare_AI.bat
```

#### Information Appears Incomplete

Review:

- Search terms
- Selected condition
- Assessment inputs

Remember that educational information may require professional interpretation.

#### Report Issues

Refresh the browser and regenerate the report.
